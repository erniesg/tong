# Shanghai H1 Generation Prompts

This document holds visual/art-direction guidance for Shanghai H1 scenes.
Character sheet files should keep physical descriptions minimal and delegate full art direction here.

## Character visual anchors (H1)

- **守成 / Shoucheng**
  - restrained streetwear palette
  - expression-first framing over costume detail
- **丁漫 / Dingman**
  - kinetic posture, playful stance shifts
  - props and food interaction convey personality
- **方阿姨 / Fang Ayi**
  - grounded neighborhood authority
  - warm framing and social-center composition

## Prompt contract note

Voice constraints and dialogue behavior belong in runtime character sheets (`apps/client/lib/content/shanghai/characters.ts`).
This doc only stores visual generation direction.
